Audio opcional
==============

Esta carpeta utiliza un archivo local proporcionado por el propietario:

- yellow.mp3: pista musical principal.

La experiencia no descarga, transforma ni redistribuye este audio. También
funciona si el archivo falta.

La música solo comienza cuando la persona visitante toca el control de sonido.
El código ajusta su volumen de forma narrativa. Usa un archivo comprimido para
web y evita un volumen master demasiado alto.
